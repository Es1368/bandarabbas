# سامانه ارزیابی عملکرد آسفالت شهرداری بندرعباس

این پروژه یک سامانه وب فارسی (RTL) برای ثبت و تحلیل عملکرد آسفالت نواحی شهرداری بندرعباس است.

## امکانات

- ثبت امتیاز کیفی ۱۸ آیتم عملکردی برای ۱۲ ناحیه (۴ منطقه × ۳ ناحیه)
- ثبت تناژ آسفالت هر ناحیه
- داشبورد هر منطقه:
  - نمودار مقایسه دسته‌های عملکردی نواحی (مرتب‌سازی بهترین تا ضعیف‌ترین)
  - نمودار مجموع امتیاز عملکردی نواحی (مرتب‌سازی بهترین تا ضعیف‌ترین)
- داشبورد مقایسه ۴ منطقه:
  - مقایسه ۳ دسته عملکردی (میانگین نواحی)
  - مقایسه مجموع امتیاز عملکردی مناطق
- داشبورد تناژ:
  - تناژ نواحی هر منطقه (نزولی)
  - مقایسه تناژ کل ۴ منطقه (نزولی)
- مقایسه کلی ۱۲ ناحیه برای:
  - مجموع امتیاز عملکردی
  - هر ۳ دسته عملکردی
  - تناژ آسفالت
- ذخیره‌سازی پایدار اطلاعات با SQLite
- تمام رابط کاربری فارسی، راست‌چین و با فونت Vazirmatn

## ساختار امتیازدهی

سه دسته اصلی:

1. **رعایت مراحل اجرایی** (۶ آیتم)
2. **تجهیزات** (۷ آیتم)
3. **نیروی اجرایی و نظارتی** (۵ آیتم)

امتیاز هر آیتم بین ۰ تا ۵ است.

- درصد هر دسته = `جمع امتیاز آیتم‌های دسته / (تعداد آیتم × ۵) × ۱۰۰`
- مجموع امتیاز عملکردی هر ناحیه = درصد ترکیبی ۱۸ آیتم
- مجموع امتیاز عملکردی هر منطقه = میانگین ۳ ناحیه همان منطقه

## پیش‌نیازها

- Python 3.10 یا بالاتر

## نصب و اجرا (لوکال)

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

سپس سامانه روی آدرس زیر در دسترس است:

- `http://127.0.0.1:5000`

> در اولین اجرا، دیتابیس `data.db` ساخته می‌شود و ۱۲ ناحیه با امتیاز و تناژ صفر به‌صورت خودکار Seed می‌شوند.

## مسیرهای اصلی سامانه

- `/` خانه
- `/data-entry` فهرست ورود داده نواحی
- `/district/<id>` فرم ثبت امتیاز و تناژ یک ناحیه
- `/region/1` تا `/region/4` داشبورد هر منطقه
- `/regions-comparison` مقایسه چهار منطقه
- `/tonnage` داشبورد تناژ
- `/overall-comparison` مقایسه کلی نواحی

## استقرار روی سرور (ساده و قابل‌میزبانی)

### گزینه پیشنهادی: Gunicorn + Nginx (Linux)

1. نصب وابستگی‌ها:

```bash
pip install -r requirements.txt gunicorn
```

2. اجرای سرویس:

```bash
gunicorn -w 3 -b 0.0.0.0:8000 app:app
```

3. Nginx را به `127.0.0.1:8000` پروکسی کنید.

نمونه حداقلی location:

```nginx
location / {
    proxy_pass http://127.0.0.1:8000;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
}
```

## نکات عملیاتی

- فایل دیتابیس: `data.db`
- برای پشتیبان‌گیری کافی است از `data.db` نسخه پشتیبان بگیرید.
- برای ریست داده‌ها، سرویس را متوقف و فایل `data.db` را حذف کنید، سپس دوباره اجرا کنید.
